The public repository open-problems-frontier contains only explicitly authorized release payloads. The intended private repository x07-open-problems-frontier is the staging location for in-scope project material.

The owner requested that routine private additions may proceed without repeated approval; major changes and copying material to public require authorization. For this setup, visibility changes, new collaborators or credentials, bulk workspace imports, history rewriting and unattended publication are major changes requiring separate approval.

The latest November16,2026 instruction explicitly authorizes the audited Cycle197package and records in the identified historical backlog that pass scoped review. This release manifest lists the exact passing payload. It does not authorize publishing held, failed, inconclusive or unaudited claims, unrelated source estates, personal/commercial records or credentials.

No automatic mirror, synchronizer or publishing workflow is installed by this setup. These are operating rules, not a claim that GitHub branch protection or a technical approval gate has been configured. Original evidence is retained locally; reference files distinguish user direction, AI assistance, academic sources and review limitations.
