## Frozen artifact and exact check

The [commit-pinned compressed source](https://raw.githubusercontent.com/Middletownbooks/Hadamard/d91311b4e36b68b9b6a9d785c3d6ef3075c8ec98/pub/H2092/H2092_normalized.txt.gz) was saved as H2092_normalized.txt.gz (historical local record; not distributed here): 43,426 bytes; SHA-256 `bfae5d317f8710c050cd971524ecf1a4f0503adef3f03a97e93372df705dc0d5`. Its computed Git blob SHA-1 `9ac89516334e91f674de38993a5451ce38389e08` matches the repository API listing at that commit. Decompression gives 4,378,556 bytes, SHA-256 `9ce7958a465a2d0f2f8e34770e8dbb435023da983c74faed171d05dfda92a5cc`, exactly 2,092 newline-terminated rows of 2,092 ASCII `+`/`-` signs.

The independently written checker (historical local record; not distributed here) was run with the bundled Python 3.12.14; system Python 3.9.6 could not run `int.bit_count` and its failed startup is not mathematical evidence. The checker requires the pinned compressed hash and strict decompressed grammar, builds exact integer bit masks, and checks Hamming distance 1,046 for **all 2,187,186 unordered distinct row pairs**. Every row has squared norm 2,092 by its sign entries. Since `h_i·h_j=2092-2d_H(h_i,h_j)`, the exact check proves `HH^T=2092I`; squareness then implies `H^TH=2092I`. Four selected pairs were separately recomputed by direct integer sign products, all zero. The certificate (historical local record; not distributed here) records source/checker hashes and controls.

**Adversarial controls and independence.** A one-sign mask mutation failed orthogonality; corrupted/truncated compressed inputs failed the pinned hash; missing-row, nonsign and wide-row decompressed controls failed grammar. Initial static inspection caught a parser condition that wrongly demanded both signs in every row, despite a legitimate all-plus normalized row; it was fixed before the deciding run. The first execution then failed because system Python lacked `bit_count`; the deciding run and all controls succeeded under Python 3.12. These are checker/environment defects found and repaired before final adjudication, not failures of the source matrix. The upstream `verify.py` was listed but never read or executed. This is an independently written exact implementation with shared public input and model convention, plus a four-pair arithmetic cross-check; it is not blind reproduction, full independent second implementation, external human review, or formal verification.
