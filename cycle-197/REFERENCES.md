## Method and provenance

The C197 reduction and certificate were rederived locally. The pinned Mathlib clique/degree definitions and Formal Conjectures Ramsey definitions were used to compare meanings, not as a completed proof of the project theorem. Formal Conjectures explicitly distinguishes statement placeholders from completed proofs. Physlib core, PhyslibAlpha and QuantumInfo have distinct review scopes; no empirical physics observation or model comparison follows from this source assessment. The Erdős project README reports that its historical AI-contribution wiki is no longer updated.

Earlier project inputs: the complete C188 six-vertex orbit ledger and C196 explicit residual list are included as data and identified by hashes. The original C197 checker and alternate were replayed read-only; the fresh checker imports neither. The fresh six-vertex census was fully recomputed. Earlier exclusions producing the prior residual list remain inherited inputs for the set-update claim.

Stephen Boyd and Lieven Vandenberghe, Convex Optimization / Stanford EE364a duality lecture chapter: https://web.stanford.edu/class/ee364a/lectures/duality.pdf. C197 used reformulation guidance; the short weak-alternative argument here follows directly from M^T y >= 0 and y^T b < 0, without a strong-duality converse.

This package contains local nonblind review and reproducible exact arithmetic, not formal verification or external mathematical review.
